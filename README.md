# 🎭 Italienne 

Application mobile pour répéter son texte de théâtre.

## Accès

👉 **[Ouvrir l'application](https://ruizjonathan198.github.io/Italienne-/)**

## Pour les enfants

1. Ouvre le lien ci-dessus dans **Chrome**
2. Tape les **3 points** en haut à droite → **"Ajouter à l'écran d'accueil"**
3. L'app s'installe comme une vraie application
4. Elle fonctionne **sans internet** une fois installée

## Fonctionnalités

- 📖 8 modes d'entraînement
- 🔊 Voix naturelles par personnage
- ▶ Auto-enchaîner
- 🎮 Quiz de mémorisation
- 🧵 Fil rouge
- 🎙 Enregistrement vocal
- 📝 Notes colorées
- 🌙 Mode sombre pour les coulisses
- 👶 Mode enfant
- ☁ Pièce partagée entre toute la troupe

## Import du texte

Formats : PDF, DOCX, TXT, ou coller le texte directement.
